# QR-анкета

Мобильная анкета по QR-коду: открытые вопросы, чекбоксы, админка, Excel и SQLite.

## Как запустить

Дважды откройте `start.bat` или в терминале:

```bat
py -3.13 -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

После старта в консоли появятся адреса:

- локальный: `http://127.0.0.1:5050/`
- в Wi‑Fi сети
- публичный HTTPS через туннель Serveo (пока сайт запущен на этом компьютере)

QR: `.../qr`  
Админка: `.../admin`  
Логин по умолчанию: `admin` / `admin123`

С телефона откройте публичный адрес или отсканируйте QR. Если публичного туннеля нет, телефон и компьютер должны быть в одной Wi‑Fi.

## Хостинг

На сервере туннель не нужен. Задайте переменные окружения:

- `DISABLE_TUNNEL=1`
- `PUBLIC_URL=https://ваш-адрес`
- `ADMIN_PASSWORD` — свой пароль, не оставляйте `admin123`
- `SECRET_KEY` — длинная случайная строка

Затем: `pip install -r requirements.txt` и `python app.py`. Порт берётся из `PORT` (Render подставляет сам).

База: файл `data/anketa.db`. На бесплатном Render диск временный — ответы могут пропасть после перезапуска. Для постоянной базы лучше маленький VPS.

## Файл вопросов

Поддерживаются `.txt` и `.xlsx`.

Колонки Excel: `type`, `question`, `options`, `correct`, `scored`  
(можно по-русски: `тип`, `вопрос`, `варианты`, `правильные`, `оценивается`)

Типы:

- `open` — открытый ответ (имя, фамилия)
- `single` — один правильный ответ
- `multiple` — несколько правильных

Пример txt — `samples/questions.txt`. Шаблон Excel скачивается из админки.

## Что хранится

SQLite-файл `data/anketa.db`: вопросы, ответы, время прохождения, процент правильности.  
Админ может выгрузить Excel за период и очистить ответы, не трогая вопросы.
